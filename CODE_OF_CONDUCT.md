# Code of Conduct

## Standard

This project expects respectful, professional collaboration. Contributors should
focus discussion on evidence, implementation risk, validation, and repository
scope. Harassment, personal attacks, discriminatory language, or deliberate
disruption are not acceptable.

## Scope

This code of conduct applies to repository issues, pull requests, discussions,
review comments, and project-related communication.

## Reporting

Report conduct concerns to the repository owner. If the concern also involves a
security issue, follow 'SECURITY.md' and avoid posting exploit or private
details publicly.

## Enforcement

The repository owner may moderate, edit, or remove inappropriate comments,
close disruptive issues or pull requests, or restrict participation when needed
to keep the project usable and safe.
